# Banco de imagens do DJDE Studio

Imagens originais para projetos feitos no DJDE Studio. Lote 1 (gerado em 11/10/2026, aprovado por Fernando Villar em 12/10/2026).

| Pasta | Conteúdo | Medidas |
|---|---|---|
| `backgrounds/` | 4 cenários (pátio, laboratório, praça, floresta) | 960 × 720 (4:3, palco) |
| `characters/` | Íris, a robô do DJDE: parada e 2 quadros de caminhada | fundo transparente |
| `objects/` | 16 objetos de jogo (moeda, estrela, chave, porta…) | fundo transparente |
| `tiles/` | 8 tiles que se repetem sem emenda (grama, terra, água…) | quadrados |

- **`assets.csv`** é o registro de cada imagem: id, descrição, medidas, prompt, modelo gerador, data, revisão, aprovação e o **SHA-256** do arquivo. Toda imagem nova ou alterada atualiza a linha correspondente.
- **`prompts/`** guarda o prompt de cada imagem, para regerar no mesmo estilo.
- Origem: geradas por IA (OpenAI GPT-image) e pós-processadas (recorte, medidas, transparência e conferência visual) pela equipe DJDE.
