DJDE Studio: privacidade

Versão provisória (12/10/2026). Esta página descreve, de forma factual, o que o código do DJDE Studio faz hoje. Ela ainda será revisada pela equipe do projeto DJDE (UFRJ), inclusive à luz da LGPD.

Não temos servidor próprio

O DJDE Studio é um site estático publicado no GitHub Pages. Seus projetos não são enviados para nenhum servidor do DJDE: eles ficam no seu computador e só saem dele quando você salva o arquivo .sb3 onde quiser. Como todo site, o GitHub (que hospeda as páginas) recebe as informações normais de uma visita, como o endereço IP; veja a política de privacidade do GitHub.

O DJDE Studio não tem telemetria, não conta visualizações e não usa variáveis de nuvem.

O que fica guardado no seu navegador

  • Preferências: idioma, tema, configurações dos addons, nome de usuário usado nos projetos e intervalo dos pontos de restauração.
  • Pontos de restauração do projeto aberto (cópias automáticas e manuais) e a mochila local.

Esses dados ficam só neste navegador e podem ser apagados limpando os dados do site.

Quando o site acessa outros serviços

  • Bibliotecas de atores, fantasias, sons e fundos: as miniaturas e os arquivos vêm do servidor de arquivos do Scratch (assets.scratch.mit.edu) ao abrir as bibliotecas e ao inserir um item. Isso vale até o banco de imagens próprio do DJDE entrar.
  • Abrir um projeto do Scratch pelo número: se você usar esse recurso, o site busca o projeto em projects.scratch.mit.edu e os dados do projeto (título, autor) por meio de trampoline.turbowarp.org. Nesse caso valem também as políticas do Scratch e do TurboWarp.
  • Projeto aberto por link (project_url): o projeto é baixado do endereço indicado no link.
  • Tutoriais com vídeo: ao abrir um tutorial, o vídeo é carregado do Wistia.
  • Extensões personalizadas: uma extensão carregada por endereço, arquivo ou texto só roda depois que você aprova. Se ela tentar acessar outros sites, o editor pede permissão, com exceção de alguns serviços de código (GitHub, GitLab, Sourcehut, GameJolt) quando você autoriza a extensão a rodar fora da área isolada.
  • Traduzir e Texto para Fala: no DJDE Studio essas extensões não usam servidores externos. O texto não sai do seu computador; a fala usa a voz do próprio navegador.
